# ch-0004（2,421 字）

苏牧把娜仁守了九年的4.8万一天花光，换回30吨干草，118头母牛的冬料补齐，手上现金归零。阿木尔收草、暂缓3.2万那张借条，要他签一张认地书确认那1500亩系阿木尔家草场，苏牧对照合同签字按指印，认地书收进阿木尔家的炕柜。回程苏牧用卷尺量了北界那条『草场边际』412步：没有界桩、没有栅栏、没有地籍号，南边苜蓿茬北边干草茬，中间只有草色变了一下——400亩只写在合同四至里。晚上娜仁把旧库房的钥匙放在灶台上，说『你爹说等你能回来再看，我说我等你回来，现在你回来了』，苏牧没有拿，说明天自己去开。

- E4-3 [decision] 阿木尔说那3.2万的借条不动也不催，暂缓不催也未作废，先把草给苏牧。｜参与：阿木尔、苏牧｜地点：巴音乌拉草场
- E4-4 [discovery] 苏牧用卷尺沿北界那条『草场边际』从老牧场道走到那林河支流，412步，没有界桩、没有栅栏、没有地籍号，南边是苜蓿茬北边是干草茬，中间只有草色变了一下。400亩只写在合同四至里。｜参与：苏牧、阿木尔｜地点：巴音乌拉草场
- E4-5 [gain] 娜仁从围裙兜里掏出旧库房的钥匙放在灶台上，说『你爹说等你能回来再看，我说我等你回来，现在你回来了』。苏牧没有拿钥匙，说明天自己去开。库房的门仍未开。｜参与：苏牧、娜仁｜地点：苏家牛场
